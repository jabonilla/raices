# Security Policy

## Reporting a vulnerability

**Do not open a public GitHub issue for a security vulnerability.**

Please report vulnerabilities privately to @jabonilla using GitHub's
private vulnerability reporting: open the **Security** tab of this
repository and choose **Report a vulnerability**. Reports are handled
confidentially and we will respond as soon as we can.

If private vulnerability reporting is unavailable to you, contact the
maintainer through a private channel instead of filing anything public.
